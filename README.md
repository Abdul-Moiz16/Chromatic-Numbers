-- MUST HAVE JAVA JDK ATLEAST ABOVE 21 AND MUST HAVE JAVA FX LIB --

-- Phase 1:
For finding the exact chromatic number of large graphs, if the program computes for more than 30 seconds it will output only the upper bound of the chromatic number. That is why we have made the program compile for 30 to 40 seconds as that is how we keep track of the compilation time. The program will always output the upper bound.

-- Phase 2:
To run the game, run GUI.java located in project_1.1\src\main\java\project1_1

-- Phase 3:
Run GUI.java located in project_1.1\src\main\java\project1_1 to start the game. Then input the desired number of vertices and edges and hit "Generate Graph" to generate and display the graph, or upload a .txt file with your graph and select it from the drop-down menu. Then click on "Choose Gamemode" and press either the "Color (Greedy)" button to color the graph using the Greedy Coloring Algorithm, or the "Color (DSatur)" button to color the graph using DSatur algorithm. To uncolor the graph click "Return". Repeat the process as you see fit.
